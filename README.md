# 数独 · 网页版 + 安卓版

两个版本使用**同一套数独算法**：随机生成完整终盘后按 180° 对称挖空，
每一步都校验唯一解，保证每道题只有一个答案。

## 📱 网页版（现在就能玩）

- 打开 `sudoku-web/index.html`（电脑浏览器或手机浏览器均可，建议 Chrome）。
- 手机上可以把文件传到手机后直接打开；也可用任意方式把文件夹放到手机存储里点开。
- 传统九宫格棋盘：81 格、横竖各 9 格、3×3 大块粗线分隔。
- 三档难度，各有独立视觉风格：**简单**（清新绿）、**普通**（经典蓝）、**专家**（玫瑰粉淡色系）。
- **专家是真难**：提示数降至 24–28，并按「解题搜索工作量 ≥ 200」筛选，只有搜索量达标的高难题目才会出现。
- **每日一题**：按日期固定生成（当天不换题），完成后自动标记，本地记住完成状态。
- **退出存档**：游戏中点"←"退出会弹出选择——保存并退出 / 不保存退出 / 继续游戏。
- **继续游戏**：主页自动显示上次未完成的进度（难度、已填格数、用时），可继续或舍弃存档。
- **上次完成**：主页保留最近一次通关记录（难度、用时、错误、日期），可查看棋盘或重玩同一题。
- **报错方式可选**：主页可切换「⚡ 及时报错」（填错立刻标红计数）或「🏁 完成后检查」（填时不提示，全部填完后自动核对，有错才标红提醒）。
- **高对比界面**：背景 / 棋盘 / 数字三层层级分明，一眼看清。
- **键盘独立配色**：数字键盘使用深色主题底色，与页面浅色背景形成明显对比，白色按键保持清爽和谐。
- **推演模式**：点击「推演」封存当前局面（类似围棋封棋），在原盘面上盖一层模拟草稿并加灰色滤镜；可自由试填，点「✓ 应用」把模拟结果覆盖到真实盘面，或直接退出作废模拟。
- **自选提示**：先点选想要提示的空格子，再点「提示」；不再按顺序自动填。
- **本地排行榜**：设置默认用户名，四个模式各自独立前十名，可看个人最佳 / 最近 / 平均对比（纯本地保存，不上传）。
- **功能解说**：主页「📖 功能解说」入口，每个功能都配图文小演示，一看就懂。
- **超数独 / X 数独**：支持四窗 Windoku 与双对角线玩法，功能与标准数独完全一致（含每日一题、独立排行榜、推演、存档等），难度优化统一。
- **在线排行榜**：可选接入排行榜服务器（在排行榜页填服务器地址），成绩自动上传、查看全网前十；不填则保持本地排名。
- 支持计时、笔记、撤销、擦除、提示、错误计数、胜利彩带。

## 🤖 安卓原生版（需 Android Studio 构建安装）

- 完整工程在 `sudoku-android/`，Kotlin + Jetpack Compose，界面清爽现代。
- 三档难度、每日一题、推演/应用、报错方式可选、完成高亮、排行榜、退出存档三选、继续游戏、上次完成记录——与网页版功能对齐。
- 详细安装步骤见 `sudoku-android/README.md`：打开工程 → 连手机 → 点 Run 即装到手机。
- 也可以直接 Build APK 后手动安装到手机。
- 建议把整个 `sudoku-android` 文件夹放到非 C 盘（如 `G:\SudokuApp`）。
